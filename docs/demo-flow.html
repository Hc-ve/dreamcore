三、录制提示（与顺序配套）

开拍前 30 分钟

启动 npm run dev（:5173）+ npm run server:uv（:3001）+ 本地 ollama 自持模型；用已有作品/收藏/足迹的账号登录；预置作品、评论点赞、足迹进度、订单。

三个必防坑

① 自持模型未启动 → 结果标注「降级」，技术亮点失效；② 首次访问欢迎弹窗拦截点击（开场拍 2 秒后点「开始探索」）；③ 图生图重绘可达数十秒 → 用已生成好的结果，别在镜头里干等。

画面与声音

1440×900 或 1920×1080、缩放 100%、隐藏书签栏、关通知、无痕窗口；TTS 讲解需进音轨；建议后期配音 + 字幕，不开 DevTools、不露控制台报错。
