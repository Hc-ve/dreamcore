01

维度一 · 视觉风格定义

Visual Identity

风格宣言：「纸 · 墨 · 印」三层视觉秩序

确立「墨韵丹青 2.0」的唯一身份表述：宣纸为底（空间）、焦墨为骨（文字与结构）、朱砂为魂（行动与强调），辅以缃金作器物高光、黛青/石绿作功能辅助色。任何界面元素的色彩必须能归入这五色体系，否则视为缺陷。

修改默认风格档 → 国风化（修 Q-03）

机制：页面已存在 [data-style="guofeng"|"feiyi"|"minimal"] 三套风格（style.css L6387-6454），问题仅在「默认档 = 旧紫调」。方案：
① js/settings.js：DEFAULTS.style 由 ''（默认）改为 'guofeng'，新用户与清空 localStorage 后直接落入国风档；
② css/ink-theme.css 追加「默认档兜底覆盖」：在 html:not([data-style]) 选择器下将 --dream-gold、hero 光斑色等旧令牌重映射为五色体系——保证即使 data-style 丢失也不出现紫调；
③ 风格选择器 UI 文案「默认/国风/非遗/极简」改为「国风/非遗/极简」，移除「默认」项（四选变三选，国风即默认）。

修改粒子氛围层同源化（修 Q-03）

js/particles.js：
① L66 紫色回退色 [0x8e44ad,0x9b59b6,0x3498db,0x1abc9c] → 墨金黛青系 [0x2d4a6b,0xa8261f,0xb8892a,0x4a6b52]（与 L32 国风回退色对齐）；
② 粒子尺寸与透明度整体下调 20%（墨点应似「宿墨飞白」而非星尘）；
③ Hero 粉紫光斑（style.css 中 hero 径向渐变）经 ink-theme.css 的 html:not([data-style]) 兜底覆盖为黛青 4% + 赭石 3% 的极淡晕染，维持「云烟」意象。
不动 three.js 场景结构，仅换色值与参数。

验收标准：清空 localStorage 冷启动 → 首页无任何紫色/粉色像素（截图采样四角+中心 5 点做色相断言，色相落在 20°-50°（赭金）与 200°-215°（黛青）区间）；风格选择器三选项切换均无违和色残留。

维度四 · 图标库选型

Iconography

自绘线性 SVG 微图标（零依赖、1.5px 朱砂描边）

选型结论：不引入第三方图标库（Font Awesome/Material 全量包 100KB+，违背零依赖与体积约束；CDN 引入又有离线风险）。自绘 12 枚内联 SVG 线性图标，统一语法：24×24 viewBox、1.5px 描边、currentColor 继承、圆头线帽——气质近「工笔白描」，与宋体同源。

新增js/icons.js 图标注册模块（修 Q-06）

模块导出 icon(name, size) → 返回 SVG 字符串；首批 12 枚：trophy（替换🏆奖杯）、medal-seal（替换🏅，或直接由印章组件替代）、lotus（替换🌸今日文化话语）、scroll（卷轴/图鉴）、compass（足迹）、camera（识图）、brush（创作）、seal（印章/认证）、spark（AI 火花）、sound（TTS 播报）、arrow-up（返回顶部）、crown-seal（三甲）。
接入方式：在 js/main.js 渲染钩子处将含 emoji 的 innerHTML 节点替换为 icon('trophy')；存量 DOM 用一次性 document.querySelectorAll 文本替换挂载（约 4 处：排行榜标题、画廊徽章、今日话语、小梦气泡装饰）。
无障碍：隐藏态 🥇🥈🥉（font-size:0）直接从模板删除而非隐藏（修读屏噪音）。

验收标准：全站 innerHTML 扫描 emoji 覆盖集（🏆🏅🌸🥇🥈🥉✨⚡）命中数为 0；图标在深浅两主题下均为 currentColor 正确着色；新增模块 ≤ 4KB。

修改滚动显现 → 渐进增强（修 Q-05，P1）

原则：内容默认可见，动画只是增强。
① js/main.js 中滚动入场动画（IntersectionObserver 添加 .reveal 类那套）的初始态由「opacity:0 translateY(24px)」改为「由 JS 启动时才注入初始隐藏类」——即 document.documentElement.classList.add('js-anim') 后 CSS 才应用 .js-anim .reveal{opacity:0}；无 JS/爬虫/打印场景内容直出；
② 优先尝试 CSS 原生 scroll-driven animations（animation-timeline: view()，Chromium 115+ 原生支持，符合「浏览器已固定 Chromium/Edge」的演示环境），JS 方案作回退；
③ prefers-reduced-motion: reduce 时全部显现动画禁用（一并覆盖粒子，README 已有降级原则）。

修改间距与密度刻度（P2 打磨）

① ink-theme.css 声明间距令牌 --sp-1:8px / --sp-2:16px / --sp-3:24px / --sp-4:40px / --sp-5:64px（8pt 基准），区块间距统一到 --sp-4/5、组件内间距到 --sp-1/2；
② hero 首屏从「100vh 独占」调整为 min-height: 86vh，让「今日文化话语」卡片钩子在 900px 高度视口内露出上半——首屏即见内容；
③ 卡片圆角虽已统一 4px，卡片内边距统一 16px，图片区与文字区比例固定 4:3 封面 + 自适应题注。

验收标准：禁用 JS 刷新 → 全部内容可见；fullPage 截图不再出现空白区；820-1440px 拖拽窗口宽度无横向滚动条。

维度七 · 交互动效设计

Motion

基准曲线不变，补三枚「东方时刻」

现有 cubic-bezier(.22,.61,.36,1) 慢出落笔曲线已全站统一（实测按钮 0.25s ✓），保持为唯一基准曲线，新增动效全部复用，不引入第二曲线。

动效规格说明与落点
印章盖章（新增）0.4s · 基准曲线评级印章首次进入视口：scale(1.6) rotate(-8deg) opacity:0 → scale(1) rotate(-2deg)，模拟钤印落纸；配合轻微 blur(2px)→0。落点：画廊卡片与排行榜（CSS animation-timeline: view() 优先，JS 回退）
水墨晕染页面切换（新增）0.3s · 基准曲线hash 路由切换时，新页面容器以径向 mask 从中心晕开（mask-image: radial-gradient 动画 mask-size 0%→220%），似墨滴入纸；路由钩子在 js/router.js 渲染完成后给容器加 .ink-in 类，动画结束自动移除。低性能设备（prefers-reduced-motion）直接跳过
回纹呼吸（新增，克制）6s 循环 · 线性页脚回纹带透明度 0.3↔0.45 缓慢呼吸，赋予「纸面活气」；仅此一处循环动画，不做大面积常驻动效
卡片 hover 抬升0.35s · 基准曲线现有 transform 保持；角花 opacity 过渡保持；统一 shadow 层级令牌 --lg-shadow-soft/medium
粒子降级—prefers-reduced-motion 时粒子静止为单帧墨点（README 降级原则一致）

验收标准：全站 transition/animation 中 cubic-bezier 字面量仅允许 (.22,.61,.36,1) 与线性两种（grep 断言）；prefers-reduced-motion 模拟下无任何位移动画；帧率（DevTools Performance）滚动无长任务 > 50ms。
