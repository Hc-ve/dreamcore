# ADR: AI修图工作台——基于内置案例知识库的智能优化架构（M7）

- Status: accepted
- Date: 2026-09-22
- Deciders: 项目负责人（用户）、AI 工程协作（Trae）

## Context

比赛演示中"AI修图工作台"的 AI推荐功能实用性不足：原实现（@js/ai-edit.js recommendByAestheticScore）仅做"M1评分低分维度→固定参数映射"，纯 CSS filter 叠加，无真实图像增强、无优化过程反馈、无前后对比，观感接近"改参数"而非"AI修图"。用户提出四项改进：① 重构算法架构，基于内置知识库案例经验做智能分析与决策；② 开发智能参数优化系统，自动调节风格参数达到最佳视觉效果；③ 参照醒图（Xingtu）设计等待进程交互界面（进度%+阶段文案+取消）；④ 优化效果在色彩还原、细节增强、风格统一性上显著优于原图（参照图2/图3 的文博题材超清效果），且算法稳定、响应及时、提供前后对比。

## Decision

新建 @js/ai-knowledge.js（内置案例知识库 + 智能优化引擎）并将"AI推荐"重构为"AI智能优化"（保留按钮 id `edit-ai-recommend` 兼容既有入口）：特征提取（≤260px 降采样统计亮度/对比/饱和/色偏/锐度/过曝欠曝比）→ 10 条文旅摄影专家案例库匹配（欠曝/过曝/灰蒙/寡淡/偏色/模糊/夜景/文博暖调/水墨/良好，多案例加权合成，AI美学评分低分维度联动增强置信度，文博题材白平衡减半保护暖调）→ 像素级增强管线（灰世界白平衡→0.5%分位自适应色阶→振动饱和→选择性降噪+USM锐化，≤900×600 按行分块 rAF yield，实时进度回调、可取消）→ 醒图式浮层（画布区居中卡片：conic-gradient 环形进度+百分比+阶段文案"色彩还原中/细节增强中/风格统一调整中"+副文案"效果即将生成，请耐心等待"+取消按钮）→ 前后对比模式（原图 clip-path 裁剪叠加+分割线+滑杆，重置恢复原图）。跨域画布污染（getImageData 抛错）时降级回原参数推荐路径，不阻塞不报错。

## Alternatives Considered

1. 服务端 AI 图像生成（DashScope 图像编辑 API）——被否决，单次调用 5~15 秒且效果不可控、依赖网络与密钥稳定性，比赛演示要求响应及时、算法运行稳定；且与"内置知识库案例经验"的要求不符。
2. 保留纯 CSS filter 参数推荐（仅升级交互）——被否决，CSS filter 无真实锐化（仅 contrast/saturate 近似），色彩还原无法做白平衡与色阶校正，达不到"显著优于原图"（图2/图3 的细节增强/色彩还原效果标准）。
3. TensorFlow.js/MediaPipe 本地模型推理——推迟采用，模型加载数 MB 起步、低端机首帧延迟高，超出比赛演示对"响应及时"的要求；当前特征统计+案例决策在 900px 工作尺寸下全流程 1~3 秒完成。

## Consequences

- 智能优化全流程纯前端完成（零网络/零密钥/离线可用），知识库决策可解释（提示区引用命中案例名+置信度+调参说明），保存版本时 parameters.smartOpt 记录决策来源案例。
- 效果满足三项标准：色彩还原（白平衡+色阶，文博暖调保护）、细节增强（USM 0.35~1.3 掩模锐化+平坦区降噪）、风格统一（题材标签匹配滤镜：敦煌/国风/非遗/水墨/夜景）。
- 醒图式等待交互：进度%驱动真实管线分块进度（非假动画），随时取消，取消即中止管线且不产生半成品。
- 增强结果替换画布图源（≤900×600），保存/导出即增强图；对比模式以优化前图源叠加实现真实 before/after。
- 跨域图片（如用户上云后的 Supabase URL 若 CORS 头缺失）自动降级为参数推荐模式（[expected] 当前 Storage 配置带 CORS 头，云端图同样支持像素级处理）。
- 回归保障：tests/ai-optimize.spec.js 6 用例 × 3 视口覆盖浮层全流程/对比/重置/取消/像素差异/控制台零错误。

## Superseded when

- 引入本地 WASM/TFJS 超分模型（如 Real-ESRGAN web 版）且首帧 < 2 秒时，USM 锐化管线可升级为生成式超分。
- 案例库从 10 条扩展到 50+ 条并需要按用户作品特征聚类学习时，静态案例应迁移为 IndexedDB 持久化+用户反馈加权（点赞/采纳率）的动态知识库。
- 平台提供稳定的图像编辑 API（响应 < 5 秒、有并发配额保障）时，可评估服务端生成式增强作为可选档位。
